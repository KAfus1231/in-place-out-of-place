# Система определения «На месте / Не на месте» и мониторинга фокус-сессий

**Кратко:** локальная on-device система мониторинга рабочего положения пользователя по данным веб‑камеры. Детектирует человека (класс `person`) в реальном времени с помощью компактной нейросети (YOLOv8n → ONNX) через OpenCV DNN, отслеживает длительность фокус-сессий и генерирует визуальные/звуковые уведомления. Реализована на C++ с многопоточностью и конечным автоматом для устойчивой работы на CPU (опционально — с поддержкой CUDA).

---

## Основные возможности

* Детекция человека в режиме реального времени (класс `person`).
* Оценка «вхождения в рабочую зону» на основе bbox (ширина, высота, площадь) и порогов.
* Фильтрация шумов через накопление последовательных кадров (framesForTrigger).
* Состояния `IN_PLACE` / `LEFT_THE_PLACE` / `OUT_OF_PLACE` (state-machine) с плавными переходами.
* Таймер фокус-сессий (thread-safe `Timer`: `start/stop/reset/elapsed`).
* Ненадёжные неблокирующие уведомления: системный балун + звуковая сирена (Media Control Interface).
* Полная on-device обработка — видео не отправляется на сервер (конфиденциальность).

## Сборка и запуск

**Требования**

* C++17 или новее
* CMake 3.16+
* OpenCV с модулем `dnn` (рекомендуется OpenCV >= 4.7)
* Компилятор: MSVC / clang / gcc
* (Опционально) CUDA и сборка OpenCV с CUDA для ускорения

**Сборка**

```bash
git clone <repo>
cd <repo>
mkdir build && cd build
cmake -DCMAKE_BUILD_TYPE=Release ..
cmake --build . --config Release
```

**Запуск**

```bash
# пример
./in_place_monitor --model path/to/yolov8n.onnx --cam 0 --conf 0.7 --nms 0.5 --frames-trigger 3
```

Параметры командной строки:

* `--model` — путь к ONNX модели (обязательно)
* `--cam` — индекс веб‑камеры или путь к видеофайлу
* `--conf` — confidence threshold (по умолчанию 0.7)
* `--nms` — nmsThreshold (по умолчанию 0.5)
* `--frames-trigger` — число кадров для стабилизации состояния
* `--warning-first` / `--warning-second` — интервалы предупреждений (в секундах)

## Конфигурация

Файл `config.json`:

```json
{
  "model": "models/yolov8n.onnx",
  "inpW": 640,
  "inpH": 640,
  "personClassId": 0,
  "confThreshold": 0.7,
  "nmsThreshold": 0.5,
  "framesForTrigger": 3,
  "SQUARE_DISTANCE_THRESHOLD": 1200,
  "WIDTH_DISTANCE_THRESHOLD": 50,
  "HEIGHT_DISTANCE_THRESHOLD": 120,
  "warningDurationFirst": 5,
  "warningDurationSecond": 20,
  "soundToPlay": "assets/alarm.mp3"
}
```

Подстройте пороги (`SQUARE_DISTANCE_THRESHOLD`, `WIDTH_DISTANCE_THRESHOLD`, `HEIGHT_DISTANCE_THRESHOLD`) под вашу камеру и сцену.

## Архитектурные заметки

1. **Подготовка модели**: YOLOv8n экспортируется в ONNX. В приложении модель загружается через `cv::dnn::readNetFromONNX()` и обрабатывается OpenCV DNN (reshape/transpose → парсинг детекций → NMS).

2. **Парсинг вывода**: выход сети приводится к матрице детекций (`detMat.reshape(...).t()`), затем для каждой строки извлекаются боксы и вероятности; фильтрация по классу `person` и `confThreshold`.

3. **Фильтрация и триггеры**: для устойчивости применяется накопительный фильтр `consecutiveInPlace` / `consecutiveNotInPlace`. Состояние считается устойчивым только при достижении `framesForTrigger`.

4. **State-machine (PlaceStatus)**: три состояния — `IN_PLACE`, `LEFT_THE_PLACE`, `OUT_OF_PLACE`. Переходы сопровождаются выводом балунов, воспроизведением звука и управлением таймером сессии.

5. **Многопоточность**: отдельный поток для таймера (`Timer::worker`), thread-safe очереди для уведомлений и плейера; атомарные флаги для корректного завершения потоков.

6. **Плейер**: реализация через Windows MCI (`mciSendStringW`) для цикличного воспроизведения mp3; безопасно останавливается вызовом `stop()`.

## Как подбирать пороги и тестировать

1. Запустите систему в контролируемой среде и снимайте лог размеров bbox при разных положениях и расстояниях.
2. Подберите пороги высоты/ширины/площади так, чтобы при нормальной посадке `isInPlace()` возвращало `true` даже при небольших поворотах корпуса.
3. Увеличьте `framesForTrigger` для большей устойчивости (но с потерей отзывчивости).
4. Для плохого освещения уменьшите `confThreshold` и компенсируйте дополнительной логикой временной фильтрации.
